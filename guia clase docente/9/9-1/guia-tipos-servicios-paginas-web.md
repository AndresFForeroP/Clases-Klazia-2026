# Guía del Docente — Tipos y Servicios de las Páginas Web
## 9.º Grado — Grupo 1

---

## Objetivo de la Clase

Al finalizar esta clase, los estudiantes deben ser capaces de:
- Clasificar los principales tipos de páginas web según su función y estructura.
- Explicar qué es un dominio web, sus partes y cómo se registra.
- Definir qué son los servicios web y analizar sus ventajas e inconvenientes.

---

## Conceptos Principales

1. **Páginas Estáticas**: Contienen información fija que no cambia con frecuencia.
2. **Páginas Dinámicas**: Generan contenido en tiempo real y responden a la interacción del usuario.
3. **Tipos de Páginas**: E-commerce, blogs, corporativas, portfolios, redes sociales, etc.
4. **Dominio Web**: Dirección legible por humanos que apunta a un servidor (Nombre de dominio + Extensión).
5. **Servicios Web**: Aplicaciones accesibles por Internet que permiten la comunicación entre diferentes sistemas (interoperabilidad).

---

## Explicación para el Docente

### Tipos de Páginas Web
Explique a los alumnos que, aunque todas las páginas web se abren en un navegador, la forma en que están estructuradas y sus objetivos comerciales o informativos son muy distintos. Diferencie entre páginas **estáticas** (cuyo código HTML no cambia al menos que se edite el archivo) y **dinámicas** (que se conectan a bases de datos y cambian de contenido en tiempo real, como Facebook o Amazon).

### El Dominio Web
Un dominio es fundamental para la identidad en línea. Consta de:
- **Nombre**: La marca o identificación elegida por el dueño (ej. `wikipedia`).
- **Extensión (TLD)**: Identifica el tipo o geografía (ej. `.com` comercial, `.org` organización, `.co` Colombia).

Destaque la importancia de registrarlo y renovarlo periódicamente; de lo contrario, se pierde la propiedad y cualquier persona puede adueñarse de él.

### Servicios Web
Son los "puentes" invisibles de Internet. Permiten que aplicaciones escritas en lenguajes distintos se comuniquen usando protocolos estándar (HTTP, AMQP). 
- **Ventajas**: Interoperabilidad (comunicar sistemas diferentes de forma barata) e integración.
- **Inconvenientes**: Cuellos de botella en rendimiento, riesgos de seguridad (inyección de código, robo de datos) y complejidad de desarrollo.

---

## Cómo Explicarlo

1. **Introducción**: Pregunte si todas las páginas web se diseñan y construyen de la misma forma. Use la pregunta inicial de la presentación para generar debate.
2. **Estáticas vs Dinámicas**: Explique la diferencia conceptual usando la analogía de un cartel (estático) versus una cartelera electrónica de un aeropuerto (dinámica).
3. **Tipos de Páginas**: Repase la tabla comparativa y pida que mencionen ejemplos locales o conocidos por ellos.
4. **El Dominio**: Dibuje en el tablero una dirección como `www.colegio.edu.co` y desglose cada parte (subdominio, nombre, extensión de propósito, extensión de país).
5. **Servicios Web**: Explique cómo su teléfono sabe el clima o cómo una tienda en línea procesa pagos con tarjeta de crédito sin salir de su página (mediante APIs/servicios web externos).

---

## Ejemplos Recomendados

- **Páginas Estáticas**: La página de una panadería del barrio que solo muestra su menú, dirección y teléfono.
- **Páginas Dinámicas**: Netflix (cada usuario ve sugerencias diferentes en tiempo real).
- **Servicios Web**: Cuando inicias sesión en un sitio web usando tu cuenta de Google o Facebook. Ese botón es un servicio web.

## Errores y Confusiones Comunes

| Error frecuente | Aclaración |
|----------------|-----------|
| Confundir dominio con URL completa | El dominio es solo `ejemplo.com`. La URL incluye el protocolo (`https://`) y la ruta (`/contacto`). |
| Pensar que "dinámico" significa que tiene animaciones | Una página con muchas animaciones de carga puede ser estática si el contenido no cambia. Dinámico significa que el *contenido* se genera o cambia según bases de datos o el usuario. |
| Creer que los servicios web son páginas web visibles | Los servicios web corren de fondo para transferir datos entre computadores; los usuarios no los ven directamente. |

## Actividad Individual — Explicación para el Docente

### Descripción
El estudiante debe clasificar cuatro sitios web cotidianos (YouTube, Amazon, Wikipedia, Instagram) identificando su tipo de página, las partes de su dominio y justificando si utilizan servicios web o no.

### Respuestas esperadas:
1. **YouTube**:
   - Tipo: Medios de comunicación / Interactiva.
   - Nombre: `youtube`, Extensión: `.com`.
   - ¿Servicios web?: Sí, para obtener la lista de videos recomendados, procesar comentarios y obtener datos de streaming en tiempo real.
2. **Amazon**:
   - Tipo: Comercio electrónico (E-commerce).
   - Nombre: `amazon`, Extensión: `.com`.
   - ¿Servicios web?: Sí, para verificar pasarelas de pago, consultar inventario en tiempo real y calcular costos de envío.
3. **Wikipedia**:
   - Tipo: Informativa / Blog.
   - Nombre: `wikipedia`, Extensión: `.org`.
   - ¿Servicios web?: Sí, para consultar y guardar artículos en la base de datos centralizada.
4. **Instagram**:
   - Tipo: Red social.
   - Nombre: `instagram`, Extensión: `.com`.
   - ¿Servicios web?: Sí, para cargar imágenes de servidores, gestionar notificaciones y mensajería en tiempo real.

### Verificación Rápida:
Revise que el estudiante diferencie el nombre del dominio de la extensión y que explique con sus propias palabras por qué se requiere comunicación entre servidores (servicios web).

### Tiempo: 5-8 minutos.
